# Дескрипторы реальной K530 (USB-кабель)

Снято 27 октября 2026, macOS 13 (Darwin 22.6, Intel MacBook), через `ioreg`. Серийных номеров нет.

## Устройство

| Поле | Значение |
|---|---|
| Product / Manufacturer | `Draconic` / `SONiX` |
| VID:PID | `0C45:5004` — совпадает с кандидатами из HidServ.dll |
| bcdDevice | `0x0112` (1.12) |
| USB | 2.0 Full Speed (12 Мбит/с), EP0 64 байта, потребление 400 мА |
| HID-интерфейсов | 2 |

## Интерфейс 0 — Boot-клавиатура + Feature 64 байта

Max in/out/feature = 8 / 1 / 64. Report ID не используются.

```
05 01 09 06 a1 01 05 07 19 e0 29 e7 15 00 25 01 75 01 95 08 81 02 95 01 75 08 81 01
95 05 75 01 05 08 19 01 29 05 91 02 95 01 75 03 91 01 95 06 75 08 15 00 26 ff 00
05 07 19 00 2a ff 00 81 00 05 0c 09 00 15 80 25 7f 95 40 75 08 b1 02 c0
```

Главное: **Feature-отчёт без ID, 64 байта** (Usage Page Consumer 0x0C, Usage 0). Это кандидат на командный канал (`HidD_SetFeature`/`GetFeature` в HidServ.dll). Предположение, не доказано.

## Интерфейс 1 — NKRO + мультимедиа + служебный канал

Max in/out/feature = 64 / 64 / 1.

| Report ID | Назначение | Тип |
|---|---|---|
| 1 | Клавиатура NKRO (бит-карта, 120 бит = 15 байт) | Input |
| 2 | System Control (Generic Desktop 0x80) | Input |
| 3 | Consumer (16 бит) | Input |
| 4 | **Vendor `FF1C:0092`**, 63 байта | Input + Output |
| 5 | Мышь (кнопки, X/Y 16 бит, колесо) | Input |

Отчёт **ID 4, 63 байта в обе стороны** — совпадает с кандидатом `FF1C:0092` из HidServ.dll. Вероятно, канал команд/ответов (Output → клавиатура, Input ← ответ). Предположение, не доказано.

Размеры отчётов подтверждены `k530diag descriptors`: Input ID 4 = 63 байта, Output ID 4 = 63 байта. Реальную длину на проводе уточнить на живом обмене.

## Что подтверждено, что нет

- Подтверждено: VID/PID, usage-пара `FF1C:0092`, наличие Feature 64 байта и vendor-отчёта ID 4.
- Не подтверждено: что именно эти каналы принимают команды подсветки, формат пакетов, контрольная сумма. Для этого нужен захват обмена штатной программы на Windows.
- Кандидаты `FFFF:0001` и `000C:0001` из HidServ.dll на этом устройстве как отдельные коллекции не видны. `0C:01` есть (Consumer), `FFFF:0001` в дескрипторах нет — возможно, фильтр допускает несколько ревизий.
