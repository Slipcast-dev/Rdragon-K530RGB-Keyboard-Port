# Проверка локального выпуска 0.3.0

Дата: 14 ноября 2026 года. Версия приложения 0.3.0, номер сборки 4.

## Выполнено

- Проверка типов всего приложения и универсальная сборка для x86_64 + arm64 с целевой macOS 11.
- `tools/k530menu/test.sh`: все четыре набора прошли — настройки, JSON-хранилище, контроллер профилей, проверка и файловая установка обновлений.
- Независимая проверка изменений кода: блокирующих ошибок не найдено.
- `codesign --verify --deep --strict` собранного приложения и копии из установочного образа.
- Создание и `hdiutil verify` образа DMG.
- Монтирование DMG только для чтения, проверка ссылки Applications, копирование `.app` во временную папку, проверка версии/build и обеих архитектур скопированного приложения. Образ после проверки извлечён.
- Подпись `update.json` существующим ключом выпуска и проверка этой подписи публичным ключом из ресурсов приложения.
- Сверка всех четырёх файлов выпуска с `dist/SHA256SUMS`.
- `git diff --check` и синтаксическая проверка shell-скриптов.

Выпуск находится в `dist/`: DMG, ZIP, подписанное описание обновления и контрольные суммы. Сборка и упаковка воспроизводятся `tools/k530menu/package.sh`; бинарные артефакты исключены из Git, исходники и инструкции сохраняются в локальном репозитории.

## Что ещё требует ручной проверки

Сервис доступа к экрану в этой сессии недоступен. Видимость нового заголовка, реальные щелчки меню и внешний вид нижней строки после изменений не проверены через UI. Читаемый заголовок реализован отдельным белым NSTextField в titlebar accessory; обе основные кнопки используют общий ButtonStyle с фиксированными размерами; строка состояния находится вне ScrollView.

Новая версия не выполняла тестовых записей в подключённую клавиатуру. Полный сетевой цикл автообновления, запуск на Apple Silicon и визуальная приёмка на macOS 11 остаются отдельными проверками. Файловые тесты установки не равны проверке живого перезапуска между опубликованными релизами.
