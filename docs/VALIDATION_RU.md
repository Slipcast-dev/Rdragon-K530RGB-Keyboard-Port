# Проверки и совместимость

## Текущий выпуск

**0.3.2, build 6**, 14 ноября 2026 года. Все четыре набора `test.sh` прошли; локальные Markdown-ссылки проверены без ошибок. Универсальная сборка и упаковка выполнены: проверены подпись приложения, DMG, версия/build, x86_64 + arm64, контрольные суммы и совпадение встроенной FAQ с текущей документацией. Публикация файлов в GitHub проверяется отдельно.

## Автоматические проверки

Из корня проекта:

```sh
./tools/k530menu/test.sh
```

Четыре набора проверяют:

| Набор | Что проверяет |
|---|---|
| `LightingSettingsTests` | HEX, допустимые значения и преобразование скорости |
| `LightingProfileStoreTests` | Сохранение, независимость наборов, валидацию и сохранность повреждённого файла |
| `LightingControllerProfileTests` | Переключение черновиков, сохранение, перезапуск, создание и удаление профилей |
| `UpdaterTests` | Доверенную подпись, подмену данных, адреса, номера сборок и откат файловой установки |

Тесты не отправляют команды в клавиатуру и не загружают релизы. `package.sh` отдельно проверяет подпись приложения, DMG и соответствие подписи манифеста публичному ключу сборки. Перед публикацией сверяются контрольные суммы, версия/build и архитектуры копии приложения из DMG.

## Зафиксированная совместимость

- Ранее подсветка проверялась человеком на K530 Draconic/Sonix `0C45:5004`, Intel/macOS: режим, яркость и цвет. Данные сохранены в [research/device](../research/device/).
- Бинарник содержит x86_64 и arm64, целевая система — macOS 11+. Наличие arm64 не заменяет запуск на реальном Apple Silicon.
- Визуальный порядок уровней скорости требует отдельного аппаратного подтверждения.
- Bluetooth, макросы, переназначение клавиш и прошивка не поддерживаются.

## Ручная приёмка

Перед выпуском проверяются на поддерживаемых Mac:

- Светлая/тёмная тема системы, читаемость панели и popover профилей, масштаб дисплея.
- Появление Dock при открытии панели, исчезновение после закрытия и повторное открытие из строки меню.
- Command+W для основного окна и справки; левый/правый щелчок значка и быстрые настройки.
- Выдача/отказ разрешения, USB-переподключение, сон/пробуждение, применение и возврат исходного состояния.
- Полный цикл обновления между двумя доступными клиенту подписанными релизами: отсрочка, загрузка, ошибка сети, установка и живой перезапуск.

Эта приёмка не объявляется выполненной на основании unit-тестов. UI-автоматизация, новая аппаратная запись и полный сетевой цикл обновления при подготовке текущей документации не выполнялись. Для приватного GitHub-репозитория текущий клиент без авторизации не получает релизы; см. [описание обновлений](UPDATES_RU.md).
