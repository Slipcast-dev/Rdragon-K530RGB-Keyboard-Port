## 1. Подтвердить оборудование — следующая работа

- [ ] Записать точную маркировку K530 и аппаратную ревизию.
- [ ] Уточнить модели MacBook и версии macOS для поддержки.
- [ ] Снять USB configuration/interface/HID report descriptors.
- [ ] Подтвердить VID/PID и Usage Page/Usage.
- [ ] Определить report ID и размеры отчётов.
- [ ] Проверить перечисление и открытие служебного интерфейса на macOS.
- [ ] Сохранить результаты в research/device/ с условиями проверки.

Готовность: устройство однозначно определяется; основной ввод не нарушен; найден пригодный интерфейс управления.

## 2. Описать протокол

- [ ] Восстановить сигнатуры используемых функций HidServ.dll.
- [ ] Записать штатный USB-обмен при чтении и одном изменении подсветки.
- [ ] Найти команды, длины, report ID, порядок байтов и checksum.
- [ ] Разделить чтение, временную запись, сохранение во flash и загрузчик.
- [ ] Найти подтверждения, ошибки, таймауты и условия безопасного повтора.
- [ ] Сохранить спецификацию и эталонные пакеты с указанием версии прошивки.

Готовность: подтверждены чтение и одно обратимое изменение на штатной прошивке.

## 3. Создать macOS-прототип

- [ ] Создать Swift-модули DeviceDiscovery, HIDTransport и K530Protocol.
- [ ] Реализовать диагностику и чтение без операций записи по умолчанию.
- [ ] Добавить одну подтверждённую команду.
- [ ] Проверить ошибки, отключение кабеля и повторное подключение.
- [ ] Проверить native x86_64 на Intel и native arm64 на Apple Silicon.

Готовность: результаты совпадают со штатной программой; обычный ввод работает.
