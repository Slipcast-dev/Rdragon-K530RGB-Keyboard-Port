Актуальная линия исходников: **0.3.1, build 5**, 14 ноября 2026 года. Это текущий план; первоначальные гипотезы портирования сохранены отдельно в `PORTING_PLAN_RU.md` и историческом разделе `HANDOFF_RU.md`.

- [x] Режим, яркость, скорость, цвет и «Разноцветный»; проверка записанных значений обратным чтением.
- [x] Резервная копия перед первой записью и возврат состояния текущего запуска.

- [x] Исправления заголовка, размеров основных кнопок и закреплённая строка состояния.

- [x] Открытое окно отображается в Dock; закрытое оставляет приложение в строке меню.
- [x] Тёмный popover профилей и кнопка профилей в нижнем ряду действий.
- [x] Контекстное меню значка по правому щелчку: панель, профили, быстрые настройки и выход.

- [x] Автозапуск и встроенная справка.

## Что подтверждено ранее

Результаты исследования устройства находятся в `research/device/`: реальная K530 Draconic/Sonix `0C45:5004`, служебный интерфейс, прочитанные профили и проверка цвета. В README сохранена историческая отметка аппаратной проверки подсветки на Intel. Сборка для arm64 не равна аппаратной приёмке на Apple Silicon.

Набор unit-тестов проверяет преобразования настроек, сохранение локальных профилей, проверку подписи обновлений и откат файловой установки. Результат конкретного запуска тестов и упаковки следует фиксировать по фактическим логам разработки, а не выводить из наличия тестовых файлов.

## Приёмка перед публикацией

- [ ] Проверить новую панель, размеры кнопок и нижнюю строку на поддерживаемых версиях macOS и масштабах дисплея.
- [ ] Проверить левый/правый щелчок значка, закрытие/повторное открытие окна, быстрые настройки и блокировку во время обмена.
- [ ] На устройстве проверить смену локальных профилей, применение, отключение USB, сон/пробуждение и разрешения.
- [ ] Проверить работу и установку на Apple Silicon, а не только наличие архитектуры в бинарнике.
- [ ] Выполнить полный цикл обновления между двумя опубликованными подписанными выпусками: отсрочка, загрузка, сеть, установка и перезапуск.
- [ ] Проверить установку из DMG и обновление в папке с доступом на запись.
- [ ] Зафиксировать поддерживаемые аппаратные ревизии и версии macOS.
- [ ] Для публичного выпуска настроить Developer ID и notarization; проверить права на стороннюю эмблему.
