# Интерфейс K530 Lighting 0.3.1

## Архитектура

- `main.swift`: AppKit-окно, читаемый заголовок, значок строки меню, контекстное меню и уведомления USB.
- `LightingView.swift`: SwiftUI-панель, одинаковые основные кнопки, компактная схема ANSI 60% и закреплённая нижняя строка состояния. Длинные сообщения сокращаются в строке; полный текст доступен в подсказке.
- `LightingSettings.swift`: черновик настроек, проверка HEX и преобразование скорости UI 1–5 в протокол 4–0.
- `LightingProfileStore.swift`: именованные локальные профили в версионируемом JSON.
- `LightingProfilesView.swift`: выбор, сохранение и управление наборами.
- `StatusMenuController.swift`: контекстное меню значка и быстрые действия.
- `LightingController.swift`: состояние панели, черновики профилей, автозапуск и последовательный HID-сервис.
- `AppUpdater.swift`: фоновые обновления, проверка подлинности, установка и перезапуск; [описание выпуска](UPDATES_RU.md).
- `FaqWindowController.swift`: встроенная справка.

Целевая платформа — macOS 11+, Intel и Apple Silicon. Внешних библиотек нет. SwiftUI встроен в AppKit через NSHostingView — [документация Apple](https://developer.apple.com/documentation/swiftui/nshostingview). Предпросмотр показывает общий цвет и не моделирует аппаратную анимацию.

## Работа с панелью

1. Откройте приложение или нажмите значок в строке меню левой кнопкой.
2. Подключите K530 по USB. При необходимости разрешите «Мониторинг ввода» и перезапустите приложение.
3. В «Профилях» выберите набор настроек. Измените эффект, цвет и уровни; HEX подтверждается Enter.
4. Сохраните настройки в выбранный локальный профиль. Это действие доступно без записи в клавиатуру.
5. Нажмите «Применить» или Command+Enter. Только после записи и обратного чтения выводится подтверждение сохранения в клавиатуре.
6. «Вернуть исходное» возвращает первые восемь байт аппаратных профилей, считанных при первом успешном подключении в текущем запуске. Перед первой записью сохраняется резервная копия на диске.

Ползунки и палитра меняют черновик, а не устройство. Эффекты с собственной палитрой отключают выбор цвета. Шестерёнка содержит перечитывание устройства, автозапуск, обновления, перезапуск, справку и выход.

## Профили приложения

Кнопка «Профили» находится в нижнем ряду действий рядом с «Вернуть исходное» и «Применить». Popover использует графитовый фон, бирюзовые акценты, собственные кнопки и поле ввода. `preferredColorScheme(.dark)` задаёт тёмную тему всему контейнеру, в том числе при светлой теме macOS.

Профиль — именованный набор режима, яркости, скорости и цвета. Наборы хранятся в `~/Library/Application Support/K530Lighting/profiles.json`; доступны выбор, сохранение, переименование, создание и удаление. Черновики разных профилей сохраняются раздельно в памяти при переключении; на диск попадает сохранённая версия. Перед выходом сохраните нужные изменения.

Это **локальные профили приложения**, а не переключатель активного внутреннего профиля K530. При применении выбранного набора сохраняется прежний подтверждённый способ записи: одинаковые настройки записываются во все три аппаратных профиля. Команда выбора активного аппаратного профиля не восстановлена и не используется.

Ошибка чтения или проверки JSON показывается пользователю. Повреждённый файл не должен молча заменяться начальными значениями.

## Значок строки меню и Dock

При показе основного окна устанавливается `NSApplication.ActivationPolicy.regular`: приложение появляется в Dock. Закрытие красной кнопкой, Command+W или пунктом «Закрыть окно» переключает политику на `accessory`: Dock скрывается, приложение остаётся в строке меню. Минимизация не считается закрытием. Повторное открытие панели возвращает обычный режим.

Пункт «Мониторинг ввода…» удалён из выпадающих меню. Кнопка открытия системных настроек сохранена в блоке отсутствующего разрешения.

- Левый щелчок открывает панель.
- Правый щелчок открывает контекстное меню: открыть/скрыть панель, выбрать профиль, быстрые параметры подсветки, применение, обновления и выход.
- Пункты «Эффект — применить» и «Яркость — применить» сразу записывают изменённые настройки в клавиатуру с проверкой результата. Выбор профиля только загружает его; для записи есть «Применить выбранный профиль». Быстрые аппаратные изменения сами по себе не сохраняют локальный профиль на диск.

Иконка доступна, пока процесс приложения работает. После «Выйти» запустите `.app` из Finder или «Программ».

## Обмен с устройством

HID выполняется в последовательной очереди. Сеанс создаётся и закрывается в одной задаче на одном потоке, чтобы callback оставался привязан к правильному CFRunLoop. UI не ожидает USB-ответов. При отключении устаревший результат операции не возвращает ложный статус подключения.

## Сборка и установка

```sh
./tools/k530menu/build.sh universal
open tools/k530menu/.build/K530Lighting.app
```

Готовый установочный образ и файлы обновления:

```sh
./tools/k530menu/package.sh
```

Результат сохраняется в `dist/` в корне проекта. Откройте DMG, перетащите `.app` в Applications, извлеките образ и запускайте установленную копию. Альтернатива для локальной сборки: `./tools/k530menu/build.sh universal install` копирует приложение в `~/Applications`.

Нужны macOS и Command Line Tools. Кэш модулей по умолчанию — `.build/ModuleCache`; его можно переопределить через `SWIFT_MODULECACHE_PATH`. Подпись ad-hoc; после обновления macOS может потребовать повторно разрешить мониторинг ввода.

## Проверки без оборудования

Все четыре набора (настройки, хранилище, контроллер профилей и обновления):

```sh
./tools/k530menu/test.sh
```

Отдельные наборы:

```sh
swiftc -module-cache-path /tmp/k530-tests-cache tools/k530menu/Sources/LightingSettings.swift tools/k530menu/Tests/LightingSettingsTests.swift -o /tmp/k530-settings-tests
/tmp/k530-settings-tests
swiftc -module-cache-path /tmp/k530-tests-cache tools/k530menu/Sources/LightingSettings.swift tools/k530menu/Sources/LightingProfileStore.swift tools/k530menu/Tests/LightingProfileStoreTests.swift -o /tmp/k530-profile-tests
/tmp/k530-profile-tests
swiftc -module-cache-path /tmp/k530-tests-cache tools/k530menu/Sources/AppUpdater.swift tools/k530menu/Tests/UpdaterTests.swift -o /tmp/k530-updater-tests
/tmp/k530-updater-tests
```

Сборка и unit-тесты не заменяют аппаратную приёмку: USB-переподключение, разрешения, эффекты, выключение подсветки, запись, откат, сон/пробуждение и повторный запуск требуют проверки на реальной K530. Отдельно проверяется визуальная компоновка на поддерживаемых версиях macOS.
