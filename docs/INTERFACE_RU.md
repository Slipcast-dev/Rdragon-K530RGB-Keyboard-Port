# Панель K530 Lighting 0.2

## Архитектура

- `main.swift`: AppKit-окно, значок строки меню и уведомления подключения USB.
- `LightingView.swift`: SwiftUI-панель и компактная схема ANSI 60%. Предпросмотр показывает общий цвет, но не моделирует аппаратные анимации.
- `LightingSettings.swift`: черновик настроек, проверка HEX и преобразование скорости UI 1–5 в протокол 4–0.
- `LightingController.swift`: состояние интерфейса, автозапуск и последовательный HID-сервис.
- `AppUpdater.swift`: фоновые обновления, проверка подлинности, установка и перезапуск; подробнее в [UPDATES_RU.md](UPDATES_RU.md).
- `FaqWindowController.swift`: встроенная справка.

Сохранена поддержка macOS 11+, Intel и Apple Silicon. Сторонние библиотеки не требуются. SwiftUI встроен в AppKit через NSHostingView — [документация Apple](https://developer.apple.com/documentation/swiftui/nshostingview).

## Использование

1. Откройте приложение или нажмите значок в строке меню.
2. Подключите K530 по USB. При необходимости разрешите «Мониторинг ввода» и перезапустите приложение.
3. Выберите эффект, цвет и уровни. HEX подтверждается Enter. Это локальный черновик; записи при перемещении ползунка нет.
4. Нажмите «Применить» или Command+Enter. Запись идёт во все три профиля, затем значения считываются и сравниваются. Только успешная проверка показывает «Настройки сохранены».
5. «Вернуть исходное» возвращает первые восемь байт профилей, считанных при первом успешном подключении в этом запуске. На диске перед первой записью сохраняется резервная копия.

Эффекты с собственной палитрой отключают выбор цвета. Шестерёнка открывает перечитывание устройства, автозапуск, обновления, справку и выход. Перечитывание сохраняет изменённый черновик; приложение показывает, что есть неприменённые изменения.

HID выполняется в последовательной очереди. Сеанс создаётся и закрывается в одной задаче на одном потоке, чтобы его callback оставался привязан к правильному CFRunLoop. Основной UI-поток не ожидает USB-ответов. При отключении устаревший результат незавершённой операции не возвращает ложный статус подключения.

## Сборка и запуск

```sh
./tools/k530menu/build.sh universal
open tools/k530menu/.build/K530Lighting.app
```

Установка по стабильному пути (заменяет предыдущую локальную сборку):

```sh
./tools/k530menu/build.sh universal install
```

Нужны macOS и Command Line Tools. Кэш модулей по умолчанию хранится в `.build/ModuleCache`; при необходимости задайте `SWIFT_MODULECACHE_PATH`. Приложение подписывается ad-hoc. После новой сборки macOS может потребовать повторно выдать разрешение ввода.

## Проверки без оборудования

```sh
swiftc -module-cache-path /tmp/k530-tests-cache tools/k530menu/Sources/LightingSettings.swift tools/k530menu/Tests/LightingSettingsTests.swift -o /tmp/k530-settings-tests
/tmp/k530-settings-tests
swiftc -module-cache-path /tmp/k530-tests-cache tools/k530menu/Sources/AppUpdater.swift tools/k530menu/Tests/UpdaterTests.swift -o /tmp/k530-updater-tests
/tmp/k530-updater-tests
```

Аппаратная приёмка: USB отключение/подключение, отказ разрешений, все эффекты, выключенная подсветка, изменение параметров, резервная копия, откат и повторный запуск. Эту приёмку нужно выполнить на реальной K530 отдельно от автоматических проверок.
