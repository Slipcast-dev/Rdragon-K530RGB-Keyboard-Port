# Передача контекста для продолжения разработки

Состояние: 21 октября 2026 года. Цель пользователя — перенести функциональность штатной программы Redragon K530RGB на MacBook с Intel и Apple Silicon и иметь возможность продолжать работу с другого ПК.

## Что уже выполнено

- Исходный установщик исследован без запуска.
- Из InstallShield извлечены три файла кабинетов/заголовка и setup.ini.
- Средствами unshield распакованы все 127 файлов; проверка целостности прошла.
- Изучены PE-заголовки, импорты/экспорты, строки, настройки интерфейса и отдельные участки дизассемблирования.
- Подготовлены архитектура и подробный план. Приложение, CLI-прототип и HID-транспорт пока не реализованы.
- Результаты собраны в переносимый архив. Хеши 127 извлечённых файлов сверены с manifest.json.

## Проверенные факты

Основное приложение — PE32 i386, C++/MFC и Win32; у него нет CLR Runtime Header. Присутствие служебного dotnetinstaller.exe относится к установщику и не делает приложение программой .NET.

HidServ.dll импортирует HidD_GetFeature, HidD_SetFeature, HidP_GetCaps, функции SetupAPI, ReadFile и WriteFile. Основная программа получает адреса функций HidServ.dll динамически. В пакете нет файлов .sys/.inf, DIFxData.ini отключает поддержку перечисленных драйверных архитектур. Это аргументы за пользовательский HID API на macOS, но ещё не доказательство его достаточности на реальном устройстве.

В ресурсах представлены подсветка, три профиля, макросы, переназначения, Magic FN. Main.ini перечисляет 19 названий RGB-режимов с номерами 1–18 и 20. Это сведения об интерфейсе, не протестированная матрица функций прошивки.

## Точки входа для дальнейшего реверса

Основное приложение: `analysis/extracted/DefaultComponent/Redragon K530RGB Keyboard.exe` после распаковки снимка.

- Предпочтительный ImageBase: `0x00400000`.
- В районе VA `0x42C947` загружается HidServ.dll.
- В районе VA `0x42C963–0x42CA39` получаются указатели на её функции.
- Таблица указателей располагается около VA `0x6E4FC8–0x6E4FF8`.
- Примеры обращений к Feature-функциям: около VA `0x4361E2`, `0x436257`, `0x4362B7`.
- По VA `0x65505C`, `0x655074`, `0x65508C` лежат кандидаты структур фильтра устройства.
- VA — адреса в образе с указанным ImageBase, а не смещения в файле и не гарантированные адреса после загрузки с ASLR.

Предполагаемая интерпретация кандидатов: VID `0x0C45`, PID `0x5004`; Usage Page/Usage `FFFF:0001`, `000C:0001`, `FF1C:0092`. Подтвердить по логике DLL и физическим дескрипторам до использования.

HidServ.dll, ImageBase `0x00400000`, экспорты:

| Имя | RVA |
|---|---|
| Init | `0x455D` |
| RequestGetDeviceCount | `0x380D` |
| RequestGetFeature | `0x3C22` |
| RequestSetFeature | `0x3C9B` |
| RequestStatusSetFeature | `0x3D14` |
| RequestWrite | `0x391F` |

Все эти данные доступны в PE-отчётах и дизассемблировании снимка. Их назначение — ускорить следующий анализ; полные сигнатуры и семантика параметров ещё не восстановлены.

## Что не установлено

- Точная модель/ревизия, MCU и версия прошивки физического экземпляра пользователя.
- Фактические USB-дескрипторы, report ID, длины отчётов и доступность служебного HID-интерфейса в macOS.
- Полная структура команд, checksum, адреса блоков настроек, подтверждения и безопасные повторы.
- Какие параметры сохраняются во flash и применяются в Bluetooth-режиме.
- Возможность настройки непосредственно по Bluetooth.
- Совместимость конкретной ревизии с OpenRGB или SonixQMK.
- Необходимые разрешения macOS и поведение при ограничениях доступа.
- Модели Intel/Apple Silicon MacBook и минимальная требуемая macOS.

## Следующая конкретная задача

Снять USB/HID-дескрипторы K530 по кабелю, сохранить в `research/device/` с указанием версии ОС, маркировки клавиатуры и версии прошивки, если её можно безопасно прочитать. Не собирать серийные номера и посторонние устройства в публичный отчёт без необходимости.

Затем на Windows-стенде записать обмен штатного приложения с клавиатурой при изменении одного параметра подсветки. Проверить отсутствие постороннего ввода в публикуемом захвате. На основании подтверждённого обмена реализовать минимальный macOS-прототип чтения/одной команды. Полный интерфейс делать после этой контрольной точки.

Нельзя считать порт завершённым по успешной сборке: требуется физическая проверка на Intel и ARM. Не отправлять неизвестные пакеты, не выполнять команды загрузчика и не прошивать устройство в рамках первого прототипа.

## Доступность материалов

Публичный репозиторий содержит документы, манифест с хешами, журналы распаковки/проверки и кандидаты HID-структур. Исходный установщик, ZIP-снимок и полные PE-отчёты остаются локальными: их публикация не выполнялась.

На исходном Mac они находятся в рабочей папке `Rdragon K530RGB Keyboard - Port/repository/`: `installers/`, `research/static-analysis.zip`, `research/application-pe.txt`, `research/hidserv-pe.txt`. Полная исходная распаковка также сохранена в `Rdragon K530RGB Keyboard - Port/analysis/`.

Для доступа с другого ПК отдельно перенести ZIP-снимок и установщик либо явно согласовать их публичную публикацию. Одного git clone достаточно для продолжения по документам, но не для повторного анализа EXE. Хеши локальных артефактов сохранены в `research/ARTIFACTS.json`.

## Как восстановить исследование

Следующие команды применимы только после отдельного переноса ZIP в `research/static-analysis.zip`; сам ZIP не хранится в публичном репозитории.

Из корня репозитория:

```sh
python3 -m zipfile -e research/static-analysis.zip restored-research
```

В Windows подойдёт `Expand-Archive` или обычная распаковка ZIP. Проверять внутренние файлы по `research/manifest.json`, учитывая префикс `analysis/` внутри архива. Установщик и сам ZIP имеют отдельные SHA-256 в `research/ARTIFACTS.json`.

Документы плана ссылаются на `analysis/...` в первоначальной структуре исследования. После указанной команды эти пути находятся под `restored-research/analysis/...`.

## Инструменты проведённого анализа

- Python 3, стандартная библиотека: поиск сигнатур и строк, чтение заголовков, выделение вложенных кабинетов, SHA-256.
- unshield из https://github.com/twogood/unshield, ветка main, загруженная 21 октября 2026 года. Его CMakeLists.txt указывал версию 1.6.2; точный commit не фиксировался. Для повторного анализа закрепить проверенный commit.
- Apple clang: локальная сборка unshield с zlib, iconv и встроенной реализацией MD5.
- LLVM objdump из Command Line Tools: PE-заголовки и дизассемблирование Intel syntax.

Для просмотра уже сохранённого снимка сборка unshield не требуется. Windows-программа в процессе анализа не запускалась, сетевой обмен и USB-операции устройства не исследованы.
