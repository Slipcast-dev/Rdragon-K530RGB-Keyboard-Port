# Redragon K530RGB — порт на macOS

Исследование штатной Windows-программы Redragon K530RGB и план создания нативного аналога для MacBook с Intel и Apple Silicon.

**Статус на 21 октября 2026 года:** выполнен статический анализ и распаковка установщика. Код macOS-приложения ещё не написан; обмен с реальной клавиатурой не проверен. EXE/DLL при анализе не запускались.

## С чего продолжить на другом компьютере

1. Прочитать [передачу контекста](docs/HANDOFF_RU.md).
2. Изучить [подробный план портирования](docs/PORTING_PLAN_RU.md).
3. Выполнять [задачи по порядку](docs/BACKLOG_RU.md), начиная с дескрипторов реальной K530.
4. Учесть: исходный установщик и полный ZIP исследования пока сохранены только на исходном компьютере; в публичный репозиторий они не загружены.

```sh
git clone https://github.com/Slipcast-dev/Rdragon-K530RGB-Keyboard-Port.git
cd Rdragon-K530RGB-Keyboard-Port
```

Документы доступны сразу после клонирования. Для восстановления полного снимка потребуется отдельно перенести `static-analysis.zip` с исходного компьютера. Подробности — в инструкции передачи контекста.

Исходный установщик не включён в публичный репозиторий. Если он отдельно перенесён в папку `installers/`, проверить его на macOS можно так:

```sh
shasum -a 256 'installers/Rdragon K530RGB Keyboard - Port.exe'
```

На Windows:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'installers/Rdragon K530RGB Keyboard - Port.exe'
```

Ожидаемый SHA-256: `de4b11b71805fc0ea76452a7c9fbe74b67a044e3a67caa538b548a3041f4c573`.

## Направление реализации

Предлагается Swift/SwiftUI + пользовательский HID API IOKit, сборка Universal 2 (`x86_64` + `arm64`). Сначала USB и штатная прошивка; Bluetooth, прошивальщик и замена прошивки рассматриваются отдельно после подтверждения возможностей устройства.

Предполагаемые VID/PID `0C45:5004` получены из статических данных, а не с физической клавиатуры. Нельзя считать их достаточным подтверждением совместимости. Наличие функции в ресурсах также не подтверждает её поддержку конкретной аппаратной ревизией.

Фирменные EXE/DLL, графические ресурсы и полный архив исследования не включены в публичную версию репозитория. Контрольные суммы сохранены для проверки отдельно перенесённых файлов. Отдельная лицензия нового проекта пока не выбрана.
